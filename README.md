# mmd_physics — MMD 物理调节(Blender 插件)

在 Blender 里调 MMD 模型的物理参数(刚体 + 关节),预览效果后导出 PMX;模型没有胸部物理时可以新建。
**当前支持胸部**;衣服、头发按同一套框架后续加入。

- 适用:用 mmd_tools 导入的 PMX,或 [Convert_to_MMD5](https://github.com/killinux/Convert_to_MMD5) 转出来的模型。
- 需要:Blender 3.6(3.6.15 上验证)+ mmd_tools。
- **使用说明:[docs/使用说明.md](docs/使用说明.md)**(安装、每个按钮、预设、调参思路、常见问题)。下面是概要和原理。

## 安装

1. 把本仓库目录(`mmd_physics`)放进 Blender 的插件目录
   `%APPDATA%\Blender Foundation\Blender\3.6\scripts\addons\`(复制或目录联接都行;联接的话改了代码重启 Blender 即生效)。
2. 偏好设置 → 插件 → 搜「MMD Physics」→ 勾选启用。
3. 3D 视图按 **N** → 侧栏 **MMD物理** 标签页。

## 用法(胸部)

1. 打开模型:`文件 → 导入 → MikuMikuDance Model (.pmx)`(Scale 建议 **0.08**,和导出的 12.5 对应),
   或直接打开转换器存的 `*_mmd.blend`。
2. 选中模型里任意一个对象 → **MMD物理 → 胸部 → 读取模型当前参数**。
   面板上会显示认到的胸部刚体/关节,比如「左: 左胸(刚体 1 / 关节 1);右: 右胸(…)」。
3. 调参数:默认**实时应用**,拖动数值马上写进模型;也可以先选**预设**再点「套用」,在它基础上微调。
4. **预览 / 导出 → 开始预览**:Build 物理并播放内置测试动作(上下颠 → 扭腰 → 前后倾 → 静止),
   看胸部怎么晃;预览中也可以接着调参数。看完点**停止并还原**。
5. **导出 PMX**(默认缩放 12.5、复制贴图),到 MMD 里实测。

「恢复初始」回到第一次读取时的参数;「保存参数 / 读取参数」存成 JSON,换模型、换工程时复用。

## 模型没有胸部物理:新建

模型里找不到胸部刚体时,「胸部」面板显示新建区。光加刚体没用——没有骨头和权重,刚体晃了网格也不动,
所以按需补齐四样:

| 补什么 | 怎么做(参数取自同系列 11 个参考 PMX 实测,按身高 H 缩放) |
|---|---|
| 胸骨 左胸/右胸 | 骨尾 = 乳尖,骨头在乳尖正后方 0.058H(胸廓里);父骨取乳房区承重最多的上半身系骨 |
| 权重 | 按到乳尖的距离高斯衰减(σ = 0.052H),从胸部骨的权重里按比例分给胸骨,每个顶点总权重不变 |
| 刚体 | 每侧一个球,半径 0.029H;物理演算、16 组、不碰撞 |
| 关节 | 胸廓的刚体 → 胸部刚体,放在骨头;胸廓没有刚体就补一个跟骨、不碰撞的锚刚体 |

步骤:

1. **检测乳尖**:自动找乳尖(胸段内、离中线够远、主要由胸部骨带动、不挂布/发骨的顶点里最靠前的一撮),
   在视图里用小球标出来,先看位置对不对。
2. 找偏了(衣服遮挡、造型特殊):Tab 进网格编辑,选中乳尖附近的几个顶点 → **用选中顶点作乳尖**
   (按左右自动分,两侧一起选就一起设);「✕」改回自动。
3. 需要的话调「骨头深度 / 权重范围 / 刚体半径」(都是 ×身高)和「初始手感」预设。
4. **新建胸部物理** → 建好后面板自动读取,直接进入调参。

- 已有带权重的胸骨(名字像胸、权重集中在一侧胸前,如参考模型的 `乳奶.L/R`)直接复用,只补刚体和关节,不造骨、不动权重。
- 模型骨名是 mmd_tools 导入的 `.L/.R` 风格时,新骨在 Blender 里叫 `胸.L/胸.R`,日文名设为 左胸/右胸,导出 PMX 就是标准名。
- 建错了点面板底部 **删除新建的胸部物理**:删掉本插件建的刚体/关节/锚刚体,新建的胸骨连同权重并回父骨,模型原有的不动。
- 验证(Fiona 未加物理的 PMX):自动乳尖、骨头/骨尾位置与 Convert_to_MMD5 的结果相差 < 0.3 mm;每个顶点总权重变化 < 1e-7;
  导出 PMX 回读骨/刚体/关节齐全;删除后完全还原。

## 参数说明

**刚体**(每侧一个或一串胸部刚体)

| 参数 | 作用 |
|---|---|
| 物理类型 | 物理演算:骨头完全由刚体带动;物理+骨位置:只带旋转、位置跟父骨,不容易被拉长;跟骨:关闭物理 |
| 形状 / 半径 | 碰撞形状和大小(Blender 长度,导出乘 12.5)。只和碰撞有关,不直接决定晃动 |
| 质量 | 越重惯性越大,甩得越远;也会让静止时更下垂 |
| 移动衰减 / 旋转衰减 | 越大晃动停得越快(0~1) |
| 反弹 / 摩擦 | 碰到别的刚体时的反弹和摩擦 |
| 碰撞组 / 不碰撞的组 | PMXEditor 编号 1~16。按下某组 = 不和该组碰撞。转换器默认胸部在 16 组、和所有组都不碰撞 |

**关节**(父骨刚体 → 胸部刚体;X 左右 / Y 上下 / Z 前后,同 PMXEditor)

| 参数 | 作用 |
|---|---|
| 旋转限制 | 能转的最大角度。「旋转对称」开着时只填一个 ±值 |
| 旋转弹簧 | 把胸部拉回原位的力。0 = 没有弹簧,静止时会垂到限位上;越大回弹越快、下垂越少 |
| 移动限制 / 移动弹簧 | 允许平移的范围和回位力,胸部一般都是 0(锁死平移) |

静止时的下垂角 ≈ 质量 × 重力 × (球心到关节的距离) / 旋转弹簧。想少垂就加弹簧,想晃得大就放宽旋转限制、减小衰减。

## 预设(胸部)

只改手感参数(物理类型、质量、衰减、反弹、摩擦、限位、弹簧),不改刚体大小和碰撞组。
表里是插件预览里(Fiona,内置测试动作)的实测,MMD 里会有出入:

| 预设 | 主要数值 | 最大摆角 | 静止下垂 | 停后余晃 |
|---|---|---|---|---|
| 参考默认 | 质量 1、衰减 0.5、±10°、弹簧 0(转换器默认) | 17° | 垂在限位上 | 4° |
| 柔软 | 衰减 0.5/0.6、±20°、弹簧 60 | 25° | 4° | 11° |
| Q弹 | 衰减 0.3、±15°、弹簧 150 | 19° | 2° | 5° |
| 紧实 | 衰减 0.7/0.85、±6°、弹簧 300 | 7° | 1° | 0.5° |
| 夸张 | 质量 1.5、衰减 0.2、±25°、弹簧 60 | 41° | 晃个不停 | 18° |
| 关闭物理 | 刚体改为跟骨 | 0 | 0 | 0 |

## 预览为什么和直接 Build 不一样

模型在 Blender 里是 PMX 的 1/12.5,mmd_tools 直接 Build 跑出来和 MMD 差很多。预览期间做了这些换算,
停止时全部还原:

- **重力** 9.8/12.5:MMD 的重力是 9.8 单位/秒²,按米算就强了 12.5 倍。
- **旋转弹簧** × 1/12.5²:旋转弹簧的量纲带长度²;线性弹簧、质量、衰减与尺度无关,不换算。
- **关节弹簧**:mmd_tools 建的约束六轴弹簧全开、阻尼 0.5,弹簧为 0 也照样阻尼,关节像泡在蜂蜜里;
  改成和 MMD 一样只在弹簧非 0 的轴开弹簧,阻尼取临界阻尼的 10%。
- **帧率** 30fps(MMD 动作的帧率)。

Blender 的刚体引擎和 MMD 的老版 Bullet 仍有差别,预览用来看幅度、方向、有没有炸,手感以 MMD 实测为准。

## 注意

- **导出前要停止预览**(导出按钮会自动停止):Build 着导出,物理把骨头带离原位,PMX 一开场关节就被拉开。
- 预览中改「物理类型」「碰撞组」要重新开始预览才生效;其他参数即改即生效。
- 「PMX 缩放」要和导入/导出用的一致(导入 0.08 ↔ 导出 12.5)。
- 插件写过的刚体会打上标记,即使改成「跟骨」也还认得(「关闭物理」能再开回来)。

## 代码结构(加衣服/头发时照这个扩)

| 文件 | 内容 |
|---|---|
| `groups.py` | 分组识别:从 mmd_tools 模型里找某类物理的刚体/关节并分左右。加衣服/头发 = 加一个 `find_*` |
| `params.py` | 一套刚体+关节参数(MMD 轴向与单位)和模型之间的读写;预设、JSON;预览时的关节换算 |
| `presets.py` | 内置预设 |
| `preview.py` | Build + 测试动作 + MMD 比例换算;停止时还原 |
| `create_breast.py` | 新建胸部物理:乳尖检测、胸骨+权重、刚体+关节、删除新建的 |
| `ops.py` / `ui.py` | 按钮和侧栏面板 |
