# mmd_physics — MMD 物理调节(Blender 插件)

在 Blender 里管 MMD 模型的物理,两块:

- **效果选择(渲染用)**:胸部、头发、裙子、其他衣物各选一种方式和预设,一键模拟 / 烘焙,一键还原,
  给在 Blender 里渲视频用。方式:**MMD 刚体**(多套预设)、**弹簧骨骼**(KawaiiPhysics 同款,Vindictus 的参数)、
  **骨骼布料**(Magica Cloth 2 风格,ROE 的参数)、**跟随骨骼**。
- **胸部刚体调参 / 新建 / 预览 / 导出 PMX**:给 MMD 用,刚体和关节的每个参数都能调;模型没有胸部物理时可以新建。

- 适用:用 mmd_tools 导入的 PMX,或 [Convert_to_MMD5](https://github.com/killinux/Convert_to_MMD5) 转出来的模型。
- 需要:Blender 3.6(3.6.15 上验证)+ mmd_tools。
- **使用说明:[docs/使用说明.md](docs/使用说明.md)**(安装、每个按钮、预设、调参思路、常见问题)。下面是概要和原理。

## 安装

1. 把本仓库目录(`mmd_physics`)放进 Blender 的插件目录
   `%APPDATA%\Blender Foundation\Blender\3.6\scripts\addons\`(复制或目录联接都行;联接的话改了代码重启 Blender 即生效)。
2. 偏好设置 → 插件 → 搜「MMD Physics」→ 勾选启用。
3. 3D 视图按 **N** → 侧栏 **MMD物理** 标签页。

## 效果选择(渲染用)

侧栏 **MMD物理 → 效果选择(渲染用)**。详细见 [使用说明](docs/使用说明.md) 第 2 节。

1. 导入 PMX(0.08,勾物理)和 VMD(0.08,margin 30)→ 选中模型 → **识别物理分组**。
2. 胸部 / 头发 / 裙子 / 其他衣物各选 **方式** 和 **预设**(参数可展开改)。
3. **模拟 / 烘焙**(场景帧范围)→ 播放;渲染前 **烘焙刚体缓存(渲染前)**。
4. 换效果再点一次「模拟 / 烘焙」;**还原** 回到用之前。

| 方式 | 胸部预设 | 头发 / 裙子 / 衣物预设 |
|---|---|---|
| MMD 刚体 | 模型原样、乳奶模板、ROE 跳舞(bustB)、Vindictus 归档(B)、C 方案(E)、柔软、Q弹、紧实、夸张 | 模型原样、稳一点、飘一点 |
| 弹簧骨骼 | Vindictus 原版(K1)、+手臂碰撞(K2)、+下半身当本体(K3)、衣服跟胸、软一点、稳一点 | Vindictus 头发 / 裙摆 / 衣物 |
| 骨骼布料 | ROE 高级场景(戳的时候 / 平时) | 头发、裙子(防穿腿)、ROE 游戏原值、布料 |
| 跟随骨骼 | — | — |

**流程**(effects.py):

1. 第一次:记下原值 —— 刚体(类型、质量、阻尼、摩擦、反弹、碰撞层)、关节(限位、弹簧)、重力、原动作、
   原来是否已建立物理。
2. 每次都从原值开始:清除物理 → 写回原值 → 动作换成原动作的新副本。
3. 选「MMD 刚体」的类按预设改刚体 / 关节(rigidfx.py);其他方式的类,摆动刚体改成跟骨(原类型记在刚体上)。
4. 建立物理,关掉刚体世界,按依赖顺序烘弹簧骨骼(kawaii.py)和骨骼布料(bonecloth.py)的链。
   挂在别的链上的链后烘;同一类、挂在同一根身体骨上的骨骼布料链合成一批算,速度快很多。
   烘的时候先把模型的网格藏起来(逐帧求值快很多),但腿和胯的碰撞体不能藏:Blender 不求值藏起来的物体,
   胶囊会一直停在第一帧,裙子撞上留在原地的胶囊就被顶起来卡住。
5. 「MMD 同款」:关节换成 MMD 的弹簧(SPRING1、没有关节阻尼、旋转弹簧 × 1/12.5²)、重力 98 单位/秒²、
   谁都不碰的刚体单独一个碰撞层。

**识别**(chains.py):胸部 = 挂着摆动刚体、名字像胸的骨;摆动骨的父骨也像胸(左胸 / breast_physics_01 / bust_1 这类锚点)
时从父骨起链,否则(乳奶模板)从它自己起链,末端补一个点。其余摆动刚体的骨按挂点骨 + 去掉数字的名字分组,
挂在头下或名字像头发的算头发,名字像裙子的算裙子。

**按下垂角定弹簧**(rigidfx.py,来自 ripper_tpose `scripts/vindictus/bust_physics.py`):旋转弹簧 = 重力力矩 / 下垂角 +
重力刚度,按 MMD 重力 98、PMX 单位;挂在胸上的吊坠、衣片也算进力矩。

验证(Blender 3.6 后台,手势舞 150 帧):Vindictus PCF_005、ROE pc_j01_nk_bs、乳奶模板的下载模型三种骨架都认对;
各方式都能烘、播放;「还原」后刚体、关节、动作、重力和原来逐项一致。弹簧骨骼在 Vindictus 模型上和旧版逐帧一样
(518 条曲线差 0)。PCF_005(1556 根骨)全部换成弹簧骨骼 / 骨骼布料,180 帧约 45 秒。
裙子(整段手势舞,链根偏离动画方向的角度):PCF_005 骨骼布料「防穿腿」左右都是 -1.7°、最大 7°,「飘一点」最大 25°,
弹簧骨骼最大 28°;乳奶模板模型的外套骨骼贴着腿走,腿胶囊不留静止重叠以后不再穿腿(陷进腿胶囊 2.5 cm → 0.1 cm),
代价是外套撑开一些。

## 用法(胸部刚体,导出 PMX 用)

1. 打开模型:`文件 → 导入 → MikuMikuDance Model (.pmx)`(Scale 建议 **0.08**,和导出的 12.5 对应),
   或直接打开转换器存的 `*_mmd.blend`。
2. 选中模型里任意一个对象 → **MMD物理 → 胸部 → 读取模型当前参数**。
   面板上会显示认到的胸部刚体/关节,比如「左: 左胸(刚体 1 / 关节 1);右: 右胸(…)」。
3. 调参数:默认**实时应用**,拖动数值马上写进模型;也可以先选**预设**再点「套用」,在它基础上微调。
4. **预览 / 导出 → 开始预览**:Build 物理并播放内置测试动作(上下颠 → 扭腰 → 前后倾 → 静止),
   看胸部怎么晃;预览中也可以接着调参数。看完点**停止并还原**。
5. **导出 PMX**(默认缩放 12.5、复制贴图),到 MMD 里实测。

「恢复初始」回到第一次读取时的参数;「保存参数 / 读取参数」存成 JSON,换模型、换工程时复用。

## 模型没有胸部物理:新建

模型里找不到胸部刚体时,「胸部」面板显示新建区。光加刚体没用——没有骨头和权重,刚体晃了网格也不动,
所以按需补齐四样:

| 补什么 | 怎么做(参数取自同系列 11 个参考 PMX 实测,按身高 H 缩放) |
|---|---|
| 胸骨 左胸/右胸 | 骨尾 = 乳尖,骨头在乳尖正后方 0.058H(胸廓里);父骨取乳房区承重最多的上半身系骨 |
| 权重 | 按到乳尖的距离高斯衰减(σ = 0.052H),从胸部骨的权重里按比例分给胸骨,每个顶点总权重不变 |
| 刚体 | 每侧一个球,半径 0.029H;物理演算、16 组、不碰撞 |
| 关节 | 胸廓的刚体 → 胸部刚体,放在骨头;胸廓没有刚体就补一个跟骨、不碰撞的锚刚体 |

步骤:

1. **检测乳尖**:自动找乳尖(胸段内、离中线够远、主要由胸部骨带动、不挂布/发骨的顶点里最靠前的一撮),
   在视图里用小球标出来,先看位置对不对。
2. 找偏了(衣服遮挡、造型特殊):Tab 进网格编辑,选中乳尖附近的几个顶点 → **用选中顶点作乳尖**
   (按左右自动分,两侧一起选就一起设);「✕」改回自动。
3. 需要的话调「骨头深度 / 权重范围 / 刚体半径」(都是 ×身高)和「初始手感」预设。
4. **新建胸部物理** → 建好后面板自动读取,直接进入调参。

- 已有带权重的胸骨(名字像胸、权重集中在一侧胸前,如参考模型的 `乳奶.L/R`)直接复用,只补刚体和关节,不造骨、不动权重。
- 模型骨名是 mmd_tools 导入的 `.L/.R` 风格时,新骨在 Blender 里叫 `胸.L/胸.R`,日文名设为 左胸/右胸,导出 PMX 就是标准名。
- 建错了点面板底部 **删除新建的胸部物理**:删掉本插件建的刚体/关节/锚刚体,新建的胸骨连同权重并回父骨,模型原有的不动。
- 验证(Fiona 未加物理的 PMX):自动乳尖、骨头/骨尾位置与 Convert_to_MMD5 的结果相差 < 0.3 mm;每个顶点总权重变化 < 1e-7;
  导出 PMX 回读骨/刚体/关节齐全;删除后完全还原。

## 参数说明

**刚体**(每侧一个或一串胸部刚体)

| 参数 | 作用 |
|---|---|
| 物理类型 | 物理演算:骨头完全由刚体带动;物理+骨位置:只带旋转、位置跟父骨,不容易被拉长;跟骨:关闭物理 |
| 形状 / 半径 | 碰撞形状和大小(Blender 长度,导出乘 12.5)。只和碰撞有关,不直接决定晃动 |
| 质量 | 越重惯性越大,甩得越远;也会让静止时更下垂 |
| 移动衰减 / 旋转衰减 | 越大晃动停得越快(0~1) |
| 反弹 / 摩擦 | 碰到别的刚体时的反弹和摩擦 |
| 碰撞组 / 不碰撞的组 | PMXEditor 编号 1~16。按下某组 = 不和该组碰撞。转换器默认胸部在 16 组、和所有组都不碰撞 |

**关节**(父骨刚体 → 胸部刚体;X 左右 / Y 上下 / Z 前后,同 PMXEditor)

| 参数 | 作用 |
|---|---|
| 旋转限制 | 能转的最大角度。「旋转对称」开着时只填一个 ±值 |
| 旋转弹簧 | 把胸部拉回原位的力。0 = 没有弹簧,静止时会垂到限位上;越大回弹越快、下垂越少 |
| 移动限制 / 移动弹簧 | 允许平移的范围和回位力,胸部一般都是 0(锁死平移) |

静止时的下垂角 ≈ 质量 × 重力 × (球心到关节的距离) / 旋转弹簧。想少垂就加弹簧,想晃得大就放宽旋转限制、减小衰减。

## 预设(胸部)

只改手感参数(物理类型、质量、衰减、反弹、摩擦、限位、弹簧),不改刚体大小和碰撞组。
表里是插件预览里(Fiona,内置测试动作)的实测,MMD 里会有出入:

| 预设 | 主要数值 | 最大摆角 | 静止下垂 | 停后余晃 |
|---|---|---|---|---|
| 参考默认 | 质量 1、衰减 0.5、±10°、弹簧 0(转换器默认) | 17° | 垂在限位上 | 4° |
| 柔软 | 衰减 0.5/0.6、±20°、弹簧 60 | 25° | 4° | 11° |
| Q弹 | 衰减 0.3、±15°、弹簧 150 | 19° | 2° | 5° |
| 紧实 | 衰减 0.7/0.85、±6°、弹簧 300 | 7° | 1° | 0.5° |
| 夸张 | 质量 1.5、衰减 0.2、±25°、弹簧 60 | 41° | 晃个不停 | 18° |
| 关闭物理 | 刚体改为跟骨 | 0 | 0 | 0 |

## 弹簧骨骼(Vindictus 同款)

「效果选择」里方式选 **弹簧骨骼**。胸部、头发、裙子都能用:骨链不再由刚体带动,改成按 KawaiiPhysics
(UE 的弹簧骨骼插件,Vindictus 用的就是它)的算法逐帧模拟,烘成关键帧。**只用于在 Blender 里渲染**。
胸链能认任意骨架(Vindictus 的 `breast_physics_01` + 36 根软组织骨、ROE / MMD 的 左胸、乳奶模板的单根骨……)。

| 参数 | 游戏的值 | 作用 |
|---|---|---|
| 刚度 | 0.05 | 每步把胸拉回动画姿势的比例,越大越硬、晃得越小 |
| 阻尼 | 0.5(衣服跟胸 0.4) | 每步速度衰减,越大越快停、越不来回弹 |
| 限角 | 10.8° | 每根胸骨最多偏离动画姿势多少度 |
| 碰撞半径 | 5 cm | 胸骨点和碰撞体的半径(游戏厘米,按两肩宽换算到模型) |
| 重力 | 0 | 游戏不加重力:胸停在模型本来的形状 |
| 角色本体 / 抵消整体移动、转动 | 不设 / 0.8 | 把某根骨(如 下半身)当游戏里的"角色",它的移动和转动只传 20% 给胸;不设 = 全身动作都算 |
| 手臂碰撞 | 关 | 游戏 `DA_Breast` 的 6 个胶囊(上臂、前臂、手前方)。按游戏数据摆在 A 姿势的模型上会压到胸上部,默认关 |
| 模拟频率 | 60 | 每秒几步,每帧拆成子步(30 fps 动作 = 每帧 2 步) |

和 MMD 刚体的区别:不加重力、阻尼按步作用在相对动画的速度上(不拖尾)、能抵消角色整体移动、限角是相对动画姿势的锥形。
算法逐行照搬 KawaiiPhysics v1.13(MIT),参数从游戏的动画蓝图字节码里读出;来龙去脉见
ripper_tpose 仓库 `reports/胸部控制方式全面调研_插件准备.md`。

## 预览、「MMD 同款」为什么和直接 Build 不一样

模型在 Blender 里是 PMX 的 1/12.5,mmd_tools 直接 Build 跑出来和 MMD 差很多。预览和效果选择的「MMD 同款」
都做了这些换算(effects.mmd_like),预览停止时全部还原:

- **重力** 98 单位/秒² 换成米(98/12.5 = 7.84 m/s²)。MMD 的重力是 9.8 × 10 单位/秒²(three.js MMDPhysics、
  saba、MMDAgent-EX 都这样;0.2 版的预览用的 9.8 小了 10 倍,已改)。
- **旋转弹簧** × 1/12.5²:旋转弹簧的量纲带长度²;线性弹簧、质量、衰减与尺度无关,不换算。
- **关节**:mmd_tools 建的约束是 SPRING2、六轴阻尼 0.5,弹簧为 0 也照样阻尼,关节像泡在蜂蜜里;PMX 的关节没有
  阻尼 → 换成 SPRING1、阻尼 0(Blender 把 SPRING1 的阻尼取反,0 = Bullet 的 1.0 = MMD 的默认)。
- **谁都不碰的刚体单独一个碰撞层**:mmd_tools 只给开始时挨着的刚体加了不碰撞约束,手臂甩过来照样把胸顶开。
- **帧率** 30fps(MMD 动作的帧率)。

Blender 的刚体引擎和 MMD 的老版 Bullet 仍有差别,预览用来看幅度、方向、有没有炸,手感以 MMD 实测为准。

## 注意

- **导出前要停止预览**(导出按钮会自动停止):Build 着导出,物理把骨头带离原位,PMX 一开场关节就被拉开。
- 预览中改「物理类型」「碰撞组」要重新开始预览才生效;其他参数即改即生效。
- 「PMX 缩放」要和导入/导出用的一致(导入 0.08 ↔ 导出 12.5)。
- 插件写过的刚体会打上标记,即使改成「跟骨」也还认得(「关闭物理」能再开回来)。

## 代码结构

| 文件 | 内容 |
|---|---|
| `chains.py` | 效果选择的分组识别:胸链(任意骨架)、头发 / 裙子 / 其他衣物的骨链 |
| `effects.py` | 效果选择的流程:原值备份、写回、刚体预设、跟骨、建立、按依赖顺序烘链、MMD 同款、还原 |
| `effects_ui.py` | 效果选择的面板、参数、按钮 |
| `rigidfx.py` | 「MMD 刚体」预设写进模型:固定值、按下垂角定弹簧、按比例 |
| `bonecloth.py` | 骨骼布料(Magica 风格)的解算、采样、写关键帧、腿和胯的碰撞体;来自 ripper_tpose 的骨骼布料插件,加了相邻链连接、「腿里的重叠也放过」开关 |
| `groups.py` | 胸部刚体面板的分组识别:胸部的摆动刚体和关节,分左右(跟骨的锚点不算) |
| `params.py` | 一套刚体+关节参数(MMD 轴向与单位)和模型之间的读写;预设、JSON;预览时的关节换算 |
| `presets.py` | 内置预设 |
| `preview.py` | Build + 测试动作 + MMD 比例换算;停止时还原 |
| `create_breast.py` | 新建胸部物理:乳尖检测、胸骨+权重、刚体+关节、删除新建的 |
| `ops.py` / `ui.py` | 按钮和侧栏面板 |
| `kawaii.py` | 弹簧骨骼解算(KawaiiPhysics v1.13 的算法)、Vindictus 的参数和手臂胶囊、末端补点;脚本接口 `bake()` / `roots_of()` / `breast_bodies()` / `bodies_follow_bones()` 不变,多条链用 `simulate()` + `write_keys()` |
| `tests/` | 检查(识别、弹簧骨骼回归、烘焙后还原、裙子对称 / 不穿腿)、对比视频、面板截图、调裙子参数的工具,见 [tests/README.md](tests/README.md) |
