# MMD Physics 使用说明

在 Blender 里管 mmd_tools 模型的物理,分两块:

- **效果选择(渲染用)**:胸部、头发、裙子、其他衣物各选一种方式和预设,一键算好,在 Blender 里渲视频。
  方式有四种:MMD 刚体(多套预设)、弹簧骨骼(Vindictus 同款)、骨骼布料(Magica Cloth 2 风格)、跟随骨骼。
- **胸部刚体调参 / 新建 / 预览 / 导出 PMX**:给 MMD 用的 PMX 调胸部刚体和关节的每个参数,没有胸部物理就新建。

原理和代码结构见 [README](../README.md)。

---

## 1. 安装

1. 准备 Blender 3.6(3.6.15 上验证)并启用 **mmd_tools**。
2. 把 `mmd_physics` 目录放进 `%APPDATA%\Blender Foundation\Blender\3.6\scripts\addons\`
   (复制,或建目录联接:改了仓库代码重启 Blender 就生效)。
3. 编辑 → 偏好设置 → 插件,搜「MMD Physics」勾选启用。
4. 3D 视图按 **N**,侧栏出现 **MMD物理** 标签页。

**从旧版升级**:插件已经启用着的话,要重启 Blender,或者在偏好设置里把插件关掉再打开,新面板才会出来。

## 2. 效果选择(渲染用)

### 2.1 快速上手

1. **导入模型**:`文件 → 导入 → MikuMikuDance Model (.pmx)`,Scale 填 **0.08**,类型里要勾上物理(Physics)。
2. **导入动作**:选中模型,`文件 → 导入 → MikuMikuDance Motion (.vmd)`,Scale 同样 0.08。
   Margin 建议填 30:开头 30 帧从静止姿势过渡到舞蹈的第一个姿势,物理不会被第一帧猛地一拽。
3. 选中模型里任意一个对象 → 侧栏「MMD物理」→「效果选择(渲染用)」→ **识别物理分组**。
   面板按类别列出找到的分组,比如「胸部(2 组)」「头发(5 组)」「裙子(1 组)」「其他衣物(3 组)」。
4. 每一类选 **方式** 和 **预设**。预设会把参数填好,点「参数」展开可以接着改。
5. 点 **模拟 / 烘焙**,算的是场景的帧范围。PCF_005 这种 1500 多根骨的模型,180 帧大约 45 秒。
6. 播放看效果。**渲染前点「烘焙刚体缓存(渲染前)」**,不然渲染时刚体每帧现算,可能和播放时不一样。
7. 想换效果:改方式或预设,再点一次「模拟 / 烘焙」。每次都从原样重新算,不会越改越乱。
   **还原**:回到第一次点「模拟 / 烘焙」之前,刚体、关节、动作、重力都恢复,插件加的碰撞体删掉。

### 2.2 四种方式

| 方式 | 怎么算 | 进 PMX / MMD 能用吗 | 适合 |
|---|---|---|---|
| MMD 刚体 | PMX 自带的刚体 + 关节,由 Blender 的物理按 MMD 的方式算。按预设改参数 | 能(PMX 本来就是这个) | 想和 MMD 里看到的一样 |
| 弹簧骨骼 | KawaiiPhysics 同款(Vindictus 游戏用的):每根骨往动画姿势拉回,有阻尼、限角、碰撞,不加重力也保持形状 | 不能,只烘成关键帧 | 胸部像游戏里那样"跟着身体晃、落后一点再回来";头发、裙摆 |
| 骨骼布料 | Magica Cloth 2 风格(ROE 游戏用的):角度恢复、角度限制、腿和胯的碰撞体、背挡(不许陷进身体)、相邻链连接 | 不能,只烘成关键帧 | 裙子不穿腿;头发 |
| 跟随骨骼 | 不模拟,刚体改成跟骨。动作里有这些骨的关键帧就照关键帧走,没有就跟着身体不动 | 能(物理类型「跟骨」) | 游戏导出的动作自带裙子 / 胸部关键帧时;或者想关掉某类物理 |

弹簧骨骼和骨骼布料的结果直接写成骨骼关键帧(动作是原动作的副本,原动作留着)。
导出 PMX 不带这些关键帧;要在 MMD 里用,只能选「MMD 刚体」。

### 2.3 预设

**胸部**

| 方式 | 预设 | 说明 |
|---|---|---|
| MMD 刚体 | 模型原样 | PMX 自带的胸部刚体和关节,不改 |
| | 乳奶模板(无弹簧 ±10°) | 本机 89% 的 MMD 模型用的:没有弹簧、三轴 ±10°、阻尼 0.5,静止时垂在限位上 |
| | ROE 跳舞(bustB) | ROE 跳舞视频用的:静止下垂 15°,上下 / 左右 / 扭转 ±25 / 20 / 5°,阻尼 0.95 |
| | Vindictus 归档(B,大摆幅) | 15 套 Vindictus PMX 现在的设置:下垂 8°、上下 ±25°、阻尼 0.5 |
| | C 方案(E,稳) | 下垂 8°、上下 ±18°、阻尼 0.99,约 1 秒停下 |
| | 柔软 / Q弹 / 紧实 / 夸张 | 插件原有的手感预设(见 3.3 节) |
| 弹簧骨骼 | Vindictus 原版(K1) | 游戏的参数:刚度 0.05、阻尼 0.5、限角 10.8°、不加重力 |
| | Vindictus + 手臂碰撞(K2) | K1 再加游戏的 6 个手臂胶囊(按游戏数据摆在 A 姿势的模型上会压到胸上部) |
| | Vindictus + 下半身当本体(K3) | K1,下半身的移动和转动只传 20% 给胸(游戏里跑跳时的感觉) |
| | Vindictus 衣服跟胸 | 阻尼 0.4,比身体稍弹 |
| | 软一点 / 稳一点 | 刚度 0.03 阻尼 0.35 限角 18° / 刚度 0.1 阻尼 0.7 限角 8° |
| 骨骼布料 | ROE 高级场景(戳的时候) | Lynn 高级 H 场景被戳时的 Magica 参数:无重力、无阻尼、根部限角 35°。游戏只在戳后 2 秒内显示,这里一直开着,晃得很大 |
| | ROE 高级场景(平时) | 同一场景平时的 Magica 参数(游戏里平时不显示) |

**头发 / 裙子 / 其他衣物**

| 方式 | 预设 | 说明 |
|---|---|---|
| MMD 刚体 | 模型原样 / 稳一点 / 飘一点 | 稳一点:阻尼至少 0.9、关节旋转限位收到 70%;飘一点:阻尼 ×0.6、限位放宽到 130% |
| 弹簧骨骼 | Vindictus 头发 | 刚度 0.2、阻尼 0.35、不限角(头发还有「飘一点」:刚度 0.1、阻尼 0.2) |
| | Vindictus 裙摆 | 刚度 0.2、阻尼 0.3、不限角、半径 4 cm,带腿和胯的碰撞体 |
| | Vindictus 衣物 | 刚度 0.2、阻尼 0.6(卫衣衣片) |
| 骨骼布料 | 头发 | 角度恢复 0.3、根 / 梢限角 15 / 50° |
| | 裙子(防穿腿) | 角度恢复 0.2、背挡、腿和胯的碰撞体、相邻链连接。很稳:手势舞里裙片最多摆 7° |
| | 裙子飘一点 | 角度恢复 0.04(Magica 默认 0.2 实际只用 20%)、根 / 梢限角 45 / 80°、惯性 0.6,其余同上:最多摆 25° |
| | ROE 游戏原值 | ROE 自己的 Magica 数值,很稳 |
| | 布料 | 饰物、飘带一类(同头发的数值) |

### 2.4 参数

**MMD 刚体**(「写法」决定显示哪些)

| 写法 | 参数 |
|---|---|
| 固定值 | 质量、移动 / 旋转衰减、旋转限制 ±°、旋转弹簧(PMX 单位,0 = 没有弹簧) |
| 按下垂角定弹簧 | 静止下垂°、扭转下垂°、上下 / 左右 / 扭转限位、衰减、吊着的刚体减重。按 MMD 重力 98 算弹簧:弹簧 = 重力力矩 / 下垂角 + 重力刚度,挂在胸上的吊坠、衣片也算进力矩 |
| 按比例 | 阻尼 ×、阻尼至少、旋转限位 × |

**弹簧骨骼**

| 参数 | 作用 |
|---|---|
| 刚度 | 每步往动画姿势拉回的比例,越大越硬、晃得越小 |
| 阻尼 | 每步速度衰减,越大越快停、越不来回弹 |
| 限角 | 每根骨最多偏离动画姿势多少度,0 = 不限 |
| 重力 | 游戏里是 0:形状保持动画姿势;要下垂感可以加 |
| 碰撞半径 | 骨点和碰撞体之间的半径(按游戏厘米,用两肩宽换算到模型) |
| 末端补点 | 链末端的骨在骨尾方向加一个虚点,末端那根骨也跟着转;单根骨的胸(乳奶模板)自动补 |
| 角色本体 | 「不设」= 全身动作都传给链。选「下半身」等 = 把它的移动和转动当成角色在跑跳,按「抵消整体移动 / 转动」只传一部分 |
| 手臂碰撞 | 只有胸部有:Vindictus 的 6 个手臂胶囊 |
| 腿和胯的碰撞体 | 自动在大腿、小腿、两胯之间加胶囊(粗细按网格量),裙子不穿腿。第一帧已经陷在胯里的部分不推 |
| 腿里的重叠也放过 | 第一帧就陷在腿胶囊里的骨,关(默认)= 推出去:骨骼贴着腿走的外套会撑开一些,但腿不会穿出来;开 = 保持原形,腿一动就从布里穿出来 |
| 模拟频率 | 每秒几步(游戏 60),30 fps 的动作每帧 2 步 |

**骨骼布料**(和骨骼布料插件同名同义)

| 参数 | 作用 |
|---|---|
| 角度恢复 | 每一步把骨段往动画方向拉回多少。最重要的参数:大了硬挺,小了飘 |
| 恢复速度衰减 | 拉回的那段位移有多少不变成速度:小了像弹簧来回弹,大了软软地回去 |
| 角度限制·根 / 梢 | 偏离动画方向最多多少度,根部到末梢按深度插值 |
| 惯性、移动 / 转动限速 | 身体的移动有多少传给布;超过限速的部分不传(快动作不会把裙子甩穿腿) |
| 背挡 | 每个点不许往身体方向退到动画位置后面太远:裙子不会陷进腿里 |
| 相邻链连接 | 同一层上相邻两条链的骨尾间距只许在第一帧的 50%~120% 之间变:环形裙子被腿顶起来时裙片不会分开 |
| 腿和胯的碰撞体、边碰撞、质点半径 | 碰撞体;边碰撞 = 骨段整段当胶囊,不会从两腿之间钻过去。静止时已经陷在胯里的部分不推 |
| 腿里的重叠也放过 | 静止时就陷在腿胶囊里的骨,关(默认)= 推出去:骨骼贴着腿走的外套会撑开一些,但腿不会穿出来;开 = 保持原形,腿一动就从布里穿出来 |
| 地面 | 布的点不许低于地面 |

**整体**

| 参数 | 作用 |
|---|---|
| 刚体怎么算 | **MMD 同款**(默认):关节换成 MMD 的弹簧(没有 mmd_tools 加的 0.5 关节阻尼,旋转弹簧按缩放换算)、重力 98 单位/秒²、谁都不碰的刚体单独一个碰撞层(手不会把胸顶开)。**mmd_tools 原样**:不换算(偏硬) |
| 重力倍数 | MMD 同款时的重力 = 98 × 这个数 |

### 2.5 分组和注意

- **识别规则**
  - 胸部:挂着摆动刚体、名字像胸的骨。摆动骨的父骨也像胸(`左胸`、`breast_physics_01`、Biped 的 bust_1 这类锚点)时,从父骨起链。
  - 头发 / 裙子 / 其他衣物:其余摆动刚体的骨,按挂点骨和去掉数字的名字分组。挂在头下或名字像头发的算头发,名字像裙子的算裙子。
  - 吊坠、飘带挂在胸上时,归其他衣物。
- **分组列表**(面板最下面):每组可以改类别(比如把屁股肉从「其他衣物」改到别的类),或取消勾选不参与(保持模型原样)。
- **挂在别的链上的链**(裙子上的飘带)会等它挂的链算完再算,跟着算好的姿势走。
- **范围**:场景的帧范围。导入 VMD 后会自动设好;只想试一段,先把帧范围改短,算得快。
- **还原只回到第一次用效果之前。** 之后在「胸部刚体」面板里改的参数,点还原也会一起撤掉。

## 3. 胸部刚体调参(导出 PMX 用)

侧栏「胸部刚体(调参 / 导出 PMX)」(默认折叠)。面板顶部显示认到的刚体 / 关节,例如「左: 左胸(刚体 1 / 关节 1);右: 右胸(…)」。
认法:名字像胸的**摆动**刚体,以及一端连着它们的关节。跟骨的锚点刚体(`左胸` / `breast_physics_01` 上的静态刚体)不算,
改了它们胸会塌。

1. 已有胸部物理:点 **读取模型当前参数**;没有:按第 4 节新建。
2. 选预设点 **套用**,或直接拖参数(默认「实时应用」,改了马上写进模型)。
3. 「预览 / 导出」→ **开始预览** 看效果 → **停止并还原**。
4. **导出 PMX**(缩放 12.5)→ 在 MMD 里测试,物理演算设为「**常に演算**」。

### 3.1 刚体

| 参数 | 作用 |
|---|---|
| 物理类型 | 物理演算 / 物理+骨位置(只带旋转,不容易被拉长)/ 跟骨(关闭物理) |
| 形状、半径 | 碰撞用的形状和大小(Blender 长度,导出乘 12.5),不直接决定晃动 |
| 质量 | 越重甩得越远,静止时也越下垂 |
| 移动衰减、旋转衰减 | 0~1,越大晃动停得越快 |
| 反弹、摩擦 | 碰到别的刚体时的反弹和摩擦 |
| 碰撞组、不碰撞的组 | PMXEditor 编号 1~16;按下某个编号 = 不和那组碰撞 |

### 3.2 关节(X 左右 / Y 上下 / Z 前后,和 PMXEditor 一致)

| 参数 | 作用 |
|---|---|
| 旋转限制 | 最多能转多少度;「旋转对称」开着时只填一个 ± 值 |
| 旋转弹簧 | 把胸部拉回原位的力;0 = 没弹簧,静止时会垂到限位上 |
| 移动限制、移动弹簧 | 允许平移的范围和回位力,胸部一般都是 0 |

### 3.3 预设

只改手感(物理类型、质量、衰减、限位、弹簧),不改刚体大小和碰撞组:

| 预设 | 感觉 |
|---|---|
| 参考默认 | Convert_to_MMD5 的默认值:±10°、没弹簧;静止时垂在限位上 |
| 柔软 | 弹簧弱,晃得慢而大,静止时略垂 |
| Q弹 | 回弹快、晃得欢,静止基本不垂(新建时的默认) |
| 紧实 | 幅度小、很快停,像穿了运动内衣 |
| 夸张 | 更重、衰减很小,动漫式大幅甩动 |
| 关闭物理 | 刚体改为跟骨,完全不晃 |

### 3.4 调参思路

- **静止时太下垂** → 加大「旋转弹簧」(下垂角 ≈ 质量 × 重力 × 球心到关节距离 ÷ 旋转弹簧)。
- **晃得不够** → 放宽「旋转限制」、调小「衰减」,或加一点「质量」。
- **晃个不停** → 调大「旋转衰减」。
- **左右要不一样** → 取消「左右联动」,用「编辑 左/右」切换。
- 调乱了点 **恢复初始**(回到第一次读取时的参数);满意的参数用 **保存参数** 存成 JSON,
  换模型时 **读取参数** 读回来(刚体大小也会一起读,换了模型请检查一下)。

## 4. 新建胸部物理(模型没有胸部刚体)

模型里找不到胸部刚体时,「胸部刚体」面板显示新建区:

1. **检测乳尖**:自动找乳尖,视图里用小球标出来,先看位置对不对。
2. 找偏了(衣服遮挡、造型特殊):按 Tab 进网格编辑,选中乳尖附近的几个顶点 →
   **用选中顶点作乳尖**(按左右自动分,两侧一起选就一起设);点「✕」改回自动。
3. 需要的话调 **骨头深度 / 权重范围 / 刚体半径**(都是 × 身高)和 **初始手感**。
   - 骨头深度:胸骨的关节在乳尖后面多深(默认 0.058)。
   - 权重范围:胸骨带动多大一片(默认 0.052,越大带动的胸部越大)。
   - 刚体半径:默认 0.029。
4. **新建胸部物理**。建好后自动读取参数,接着按第 3 节调。

新建做了什么:

- **胸骨**:骨尾在乳尖、骨头在胸廓里,挂在胸部承重最多的上半身骨下;导出名是 左胸/右胸。
- **权重**:按离乳尖的远近从胸部骨的权重里分给胸骨,每个顶点的总权重不变。
- **刚体 + 关节**:每侧一个球形刚体,关节连到胸廓的刚体;胸廓没有刚体就补一个跟骨、不碰撞的锚刚体。
- 模型已有带权重的胸骨(比如 `乳奶.L/R`)会直接复用,只补刚体和关节,不造骨、不动权重。

建错了:点面板底部 **删除新建的胸部物理**。只删本插件建的东西,新建的胸骨连同权重并回父骨,模型原有的不动。

## 5. 预览

「预览 / 导出」→ **开始预览**:Build 物理并播放测试动作(上下颠 → 扭腰 → 前后倾 → 静止看余晃)。
也可以把「预览动作」改成「场景现有动作」,用你自己导入的 VMD。

- 预览中可以接着调参数,大多即改即生效;改「物理类型」「碰撞组」要重新开始预览。
- 看完一定点 **停止并还原**:删掉测试动作,场景的重力、帧率、姿势都恢复原样。
- 预览按「MMD 同款」换算:重力 98 单位/秒²(9.8 × 10,three.js / saba / MMDAgent-EX 都这样)、
  关节没有 mmd_tools 加的 0.5 阻尼、旋转弹簧按缩放换算、谁都不碰的刚体单独一层。Blender 和 MMD 的物理引擎仍有差别,
  **只用来看幅度和有没有炸,手感以 MMD 实测为准**。

## 6. 导出与在 MMD 里测试

1. 点 **导出 PMX**,缩放默认 12.5(和面板上「PMX 缩放」一致),默认复制贴图——存到单独的文件夹。
   导出前会自动停止预览:Build 着导出的话,物理会把骨头带离原位,PMX 一开场关节就被拉开。

## 7. 常见问题

| 现象 | 怎么办 |
|---|---|
| 侧栏没有「MMD物理」 | 偏好设置里启用插件;确认 mmd_tools 也启用了 |
| 面板说「选中 MMD 模型里的任一对象」 | 点一下模型的骨架或网格 |
| 升级后看不到「效果选择」 | 重启 Blender,或者把插件关掉再打开 |
| 「识别物理分组」什么都没找到 | 导入 PMX 时没勾物理;或模型本来就没有摆动刚体 |
| 某组被分错了类 | 在分组列表里改它的类别,再点「模拟 / 烘焙」 |
| 渲染出来和播放时不一样 | 渲染前点「烘焙刚体缓存(渲染前)」 |
| 环形裙子用骨骼布料时裙片分开 | 打开「相邻链连接」(裙子预设默认开) |
| 裙子、外套被腿撑得鼓起来 | 腿的碰撞体(骨架下的线框胶囊,名字「骨骼布料碰撞体_…」,渲染时看不见)比腿粗:选中缩小(X/Z 缩放改半径,Y 改长度),再点「模拟 / 烘焙」。有的模型外套的骨骼本来就贴着腿走(下载的乳奶模板模型):不撑开就只能穿腿,要原形就勾「腿里的重叠也放过」 |
| 按钮是灰的 | 先点一下模型的骨架或网格;「用选中顶点作乳尖」只能在网格编辑模式(Tab)下用 |
| 检测不到乳尖 | 胸部被衣服盖住或是平胸:进网格编辑手动选顶点指定 |
| 预览时胸部不动 | 物理类型是不是「跟骨」;旋转限制是不是 0 |
| 导出后在 MMD 里太小/太大 | 导出缩放和导入时不对应(导入 0.08 ↔ 导出 12.5) |
| 导出的 PMX 一开场胸部乱飞 | 导出时模型还在 Build 状态;用本插件的「导出 PMX」会自动处理 |

## 8. 已知限制

- **弹簧骨骼、骨骼布料只用于 Blender 渲染。** 结果是关键帧,导出 PMX 不带。
- **骨骼布料是一条条链。** 相邻链之间只有间距约束,没有真正的布面,所以大幅翻动时裙片之间的网格还是会被拉长一些。
- **按下垂角定弹簧只改挂胸的那个关节。** 多段胸(RGBA 式、Tda 式)的其他段不改。
- **新建胸部只支持 MMD 标准的上半身骨。** 要有 上半身/上半身2 这类骨,模型要面朝 -Y(mmd_tools 导入的都是)。
- **胸部刚体面板是每侧一套参数。** 已有多段胸部物理的模型可以调,但各段用同一套参数。
