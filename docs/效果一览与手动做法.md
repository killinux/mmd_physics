对应插件 0.5.0。前面一张总表;后面每种效果一节,写清楚它是什么、插件里点哪里、**不用插件时手动怎么做**。
用到的数值都在附录,由 `tests/doc_tables.py` 直接从插件代码(`kits.py`、`presets.py`)生成,和插件里的预设一字不差。

各效果的对比视频在本机 `E:\game_export\_mmd_physics\效果对比\`,带图和视频的使用说明是同目录的
`MMD物理_使用说明.html`(都不在仓库里)。界面名称按中文界面写,括号里是英文原名。

## 1. 先对照:PMXEditor、mmd_tools 和 Blender 物理

手动改有两条路:**给 MMD 用就在 PMXEditor 里改**(轴和 MMD 一样,最直观);**在 Blender 里渲染**就在 mmd_tools 的面板里改
(轴要换算,见下表),或者用插件的「胸部刚体调参」面板(按 PMXEditor 的轴显示,自动换算)。

- **单位**:mmd_tools 导入缩放 0.08,Blender 里的长度 × 12.5 = PMX 单位。一个 MMD 模型大约 20 个单位高(1.6 米)。
- **轴**:PMX 的 X 左右、Y 上下、Z 前后(模型面朝 −Z);Blender 的 X、Y、Z = PMX 的 X、Z、Y。
- 本文把关节的三个转动方向叫 **上下摆**(绕左右轴,PMX 的 X)、**左右摆**(绕竖轴,PMX 的 Y)、**扭转**(绕前后轴,PMX 的 Z)。

**刚体**:PMXEditor「剛体」页;Blender 里选中刚体 → 物体属性 → MMD Rigid Body。

| PMXEditor | mmd_tools / Blender | 说明 |
|---|---|---|
| 物理演算:ボーン追従 / 物理演算 / 物理+ボーン位置合わせ | Rigid Type:骨骼 / 物理 / Physics + Bone | 跟骨不动 / 物理带动骨 / 物理带动骨、骨的位置跟父骨 |
| 質量 | 质量 | |
| 移動減衰 / 回転減衰 | 阻尼:线性拖拽 / 空阻(Linear / Angular Damping) | 0–1,越大停得越快 |
| 反発力 / 摩擦力 | 弹跳力 / 摩擦 | |
| グループ / 非衝突グループ(1–16) | Collision Group / Collision Group Mask(0–15) | Mask 按亮的组 = 不和它碰 |

**关节**:PMXEditor「Joint」页;Blender 里选中关节 → 物体属性 → MMD Joint。

| PMXEditor | mmd_tools / Blender | 换算 |
|---|---|---|
| 剛体A / 剛体B | Object 1 / Object 2 | 挂着胸的关节,剛体B(Object 2)是胸刚体 |
| 移動制限 下限 / 上限 | 第一组三行(X / Y / Z,每行左边下限、右边上限) | Blender 的 X、Y、Z = PMX 的 X、Z、Y,再 × 0.08 |
| 回転制限 下限 / 上限(度) | 第二组三行 | 轴同样换;Blender 下限 = −(PMX 上限),上限 = −(PMX 下限)。±对称的限位只要把轴换过来 |
| ばね定数-移動 / ばね定数-回転 | Spring(Linear) / Spring(Angular) | 轴同样换,数不变(Blender 实际用的弹簧硬度见 9.2) |

**改完在 Blender 里生效**:侧栏(N)→ MMD 页签,模型那一栏中间一列「Physics:」下面有上下两个按钮,先点下面的 Clean、再点上面的 Build(重建物理;中文界面可能显示成「清空」「建形」)。后文简写成 Clean → Build。

## 2. 胸部 · MMD 刚体 · 固定值

**是什么**:不改结构,只改模型自带的胸部刚体和挂它的关节:质量、阻尼、上下摆 / 左右摆 / 扭转的 ±限位、旋转弹簧,
平移锁死。乳奶模板(本机 89 % 的 MMD 模型用的:没有弹簧、±10°、阻尼 0.5,静止时垂在限位上)、PmxTailor 胸、
柔软 / Q弹 / 紧实 / 夸张都是这种。数值见附录 B.1。

**插件里**:效果选择 → 胸部 → 方式「MMD 刚体」→ 预设;展开「参数」能改单项。

**手动 · PMXEditor**(左右各做一遍):

1. 「剛体」页:找挂在胸骨上、物理演算是「物理演算」的刚体(名字常是 左胸 / 乳奶1 / breast…),填 質量、移動減衰、回転減衰。
2. 「Joint」页:找剛体B 是这个刚体的关节。移動制限 上下限全填 0;回転制限 X、Y 填 −摆动 / +摆动,Z 填 −扭转 / +扭转;
   ばね定数-回転 三格都填旋转弹簧;ばね定数-移動 全填 0。

**手动 · Blender**:选胸刚体 → MMD Rigid Body:质量、线性拖拽、空阻。选它的关节 → MMD Joint:第一组(移动)全填 0;
第二组 X 填 ±摆动、**Y 填 ±扭转**、**Z 填 ±摆动**(Blender 的 Y 是 PMX 的 Z);Spring(Angular) 三格填弹簧。
然后 Clean → Build,再做 9.2。

## 3. 胸部 · MMD 刚体 · 按下垂角定弹簧

**是什么**:MMD 里胸刚体挂在关节上,重力往下拉、弹簧往回顶,两边平衡时停在某个角度。先定「静止时垂几度」,
弹簧按 MMD 的重力(98 单位/秒²)反算。ROE 跳舞(bustB,垂 15°)、Vindictus 归档(B,垂 8°、摆幅大)、
C 方案(E,垂 8°、阻尼 0.99,约 1 秒停下)都是这种,数值见附录 B.1。

**手算**(都用 PMX 单位):

```
上下摆的旋转弹簧 ≈ 质量 × 98 × 力臂 ÷ 下垂角(弧度)
```

- 力臂 = 胸刚体的中心在关节**前方**多远(两者 PMX 坐标 Z 之差的绝对值;模型面朝 −Z)。
- 胸上还吊着别的摆动刚体(吊坠、衣片)时,把它们的「质量 × 力臂」也加进去。
- 左右摆的弹簧用同一个数;扭转用「扭转下垂角」(预设都是 4°)按同样的式子算,也不小于上下摆那个。
- 插件还加一项「重力刚度」修正(刚体偏在关节上方或下方时才有),手算可以不管。

例:质量 1、力臂 1.0(约 8 cm)、下垂 15°(0.262 弧度):98 × 1 × 1.0 ÷ 0.262 ≈ **374**;下垂 8° 约 **702**。

**手动**:算好的数填进挂胸关节的 ばね定数-回転(X 上下摆、Y 左右摆、Z 扭转);回転制限按预设填(如 bustB:上下 ±25°、
左右 ±20°、扭转 ±5°);移動減衰 / 回転減衰填在胸刚体上。Blender 里同第 2 节:Spring(Angular) 三格的顺序是
X 上下摆、Y 扭转、Z 左右摆。

## 4. 胸部 · 整套换上(多段套件)

**是什么**:把模型原来的胸部刚体换成 MMD 社区现成的一整套刚体和关节。

| 套件 | 每侧 | 怎么晃 | 数值来源 |
|---|---|---|---|
| RGBA 式 1.5β | 6 刚体 / 9 关节,没有弹簧 | 带上下颠;结构本身锁死,靠 MMD 关节的「软」晃 | mmd_jiggle_bones 附带的 RGBA_L.pmx(原版 BowlRoll 137970) |
| Tda 式 | 4 / 4 | 很稳,尖端能前后颠 | 本机 Tda式ミクBB R-18.pmx |
| 欧美 XPS 转换式 | 4 / 3 | 甩得最大,只往下摆 | 本机 Android 18 (Supergirl Malfunction).pmx |
| AH 式 | 5 / 7,另有左右之间 2 个「着衣用」 | 最小最快的「颤」(プリン);着衣用 = 左右锁在一起 | 本机 Chainsaw Man Makima by Animanpower.pmx(原版 BowlRoll 21041) |

这些套件的原版也都只有一根胸骨带权重(Tda 的「胸上2」、AH 的「胸」;欧美转换式三段都带,但动起来是一整块),
所以套件只驱动模型自己那根胸骨。

**插件怎么装**(效果选择 → 胸部 → MMD 刚体 → 预设选 RGBA / Tda / 欧美 / AH):

1. 模型原来挂胸的摆动刚体改成跟骨;
2. 每条胸链建一套:套件的「胸根 → 乳尖」对到模型的「胸骨骨头 → 乳尖」。乳尖 = 胸骨带的顶点(权重 > 0.3)里最靠前的
   3 %,左右取镜像平均;先绕竖轴转、再按上下倾角转(不滚),等比缩放 s = 模型的胸根到乳尖 ÷ 套件的胸根到乳尖;
3. 刚体尺寸、位置、平移限位 × s,旋转弹簧 × s²;质量、阻尼、旋转限位、平移弹簧不变;
4. 主刚体绑模型的胸骨,锚刚体绑胸骨的父骨,其余辅助刚体不绑骨;套件的刚体谁都不碰;
5. Blender 专用的改动:RGBA 物理步长 60 Hz、两处「托高」改 0;AH 质量 ×3;AH 着衣用质量 ×10,再加左右锁死的关节。

**手动 · PMXEditor(给 MMD 用)**:社区的做法(B 站 BV1bz411v7Ca 有完整步骤):

1. 拿到套件模型(上表「数值来源」);
2. 在 PMXEditor 里把套件模型「追加」读进来(模型合并),骨骼按名字合并;
3. 整套移动、缩放、转动,让套件的胸根落在模型胸骨的骨头上、乳尖方向对上(两点的坐标见附录 A);
4. 主刚体(附录 A 标「主」的)绑模型的胸骨,锚刚体绑胸骨的父骨(上半身2 一类),模型原来的胸刚体改成 ボーン追従;
5. 只有左边就镜像出右边(X 取反,旋转的 Y、Z 取反)。

MMD 里不用改步长、托高和质量:这些套件本来就是在 MMD 里调好的。

**手动 · Blender**:最省事的是先在 PMXEditor 做好,再用 mmd_tools 导入;RGBA 还可以用 mmd_jiggle_bones 插件一键移植
(模型要先有胸骨和胸部物理)。导入以后再做 Blender 专用的几项:

- RGBA:场景的每帧子步数改 2(60 Hz,见 9.1);关节「後2」「前2」上下方向(Blender 里是 Z 那一行)的平移下限、上限
  (原来都是 0.3 / 0.33 的固定偏移)改成 0。
- AH:五个刚体的质量都 ×3;想要着衣用就再加一个关节,Object 1 / 2 是左右两个 AH2,移动、旋转限位全 0,并且质量 ×10。

逐个在 mmd_tools 里新建刚体和关节(侧栏 MMD → Rigid Bodies / Joints 的 + 号),数值照附录 A 按上面的缩放规则换算,
也能做,只是每侧十几项,很费事。

## 5. 头发 / 裙子 / 其他衣物 · MMD 刚体

**是什么**:模型自带的刚体,阻尼和关节限位按比例改。稳一点:阻尼至少 0.9、关节旋转限位 × 0.7(晃得小、停得快);
飘一点:阻尼 × 0.6、旋转限位 × 1.3(晃得大、停得慢)。见附录 B.2。

**手动**:这一类骨上的每个摆动刚体,移動減衰、回転減衰乘上倍数(不低于「至少」那个数、不超过 1);吊着它们的每个关节,
回転制限的上下限乘上倍数。PMXEditor 和 Blender 都一样,只是项目多。

### 5.1 原来不动的链 · 新建刚体

**是什么**:转换来的模型(XPS、别的游戏)头发、裙子的骨链在,却没有刚体(列表里标「无刚体」),或者只有跟骨刚体
(「原来不动」),MMD 里一动不动。写法「新建刚体」给这些链临时建一套:每根骨一个胶囊(物理),每根骨的头上一个关节,
链根挂在挂点骨上的一个跟骨小球上;新建的刚体谁都不碰。数值见附录 B.2 的「新建刚体」一行。

**插件里**:识别物理分组 → 这一类选 MMD 刚体 → 预设「新建刚体(给原来不动的链)」(一类里全是这种链时识别后自动换上)。
弹簧骨骼、骨骼布料不用建刚体,直接能用。

**手动(Blender + mmd_tools)**,效果和插件一样,只是要一条条做:

1. 选骨架进姿态模式,选中一条链的骨 → 侧栏 MMD 页签 →「刚体」(Rigid Bodies)面板,列表右边的「+」(Add Rigid Body):
   形状 Capsule、刚类型(Rigid Type)选「物理」;再单独选链根的父骨(头、下半身)加一个,刚类型选「骨骼」,当锚。
   新刚体的碰撞组遮罩(Collision Group Mask)全按亮 = 谁都不碰(不然一开始挨着头就炸开)。
2. 物体模式,选中这条链的刚体和锚 →「关节」(Joints)面板的「+」(添加关节,Add Joint):勾「Use Bone Rotation」,
   它给每对「子骨的刚体 + 父骨的刚体」在子骨的头上建一个关节,关节的 Z 轴沿骨(扭转)。旋转限位(默认 ±45°)改成
   X、Y ±30°(摆动)、Z ±5°(扭转),移动限位全 0。
3. 旋转弹簧(Spring(Angular)):填 0 也能动,就是平伸的链(刘海)会垂下来;要撑住按插件的算法:
   弹簧(PMX 单位)= 重力刚度 + (静止时的重力力矩 + 0.2 × Σ 质量 × 98 × 力臂) ÷ 下垂角(弧度),
   n 节的链每个关节分到的下垂角 = 2 × 整条链的下垂角 ÷ (n + 1)。垂着的链弹簧接近 0,平伸、朝上的很大。
   本机 Bunny.pmx 侧发(4 节)链根的关节约 210 / 260 / 510,梢上的约 24 / 10 / 17。
4. Clean → Build。

**手动(PMXEditor)**:「剛体」页每根骨加一个(関連ボーン = 那根骨,形状カプセル,物理演算;链根的父骨加一个ボーン追従的
当锚),非衝突グループ全勾;「Joint」页相邻两个刚体之间各加一个(位置在子骨的头上,回転制限 ±30°、扭转 ±5°)。
数量多时用 PmxTailor 这类自动建布物理的工具。PMXEditor 里做的会存进 PMX,MMD 里也能用;插件的是渲染用、还原就删。

## 6. 弹簧骨骼(KawaiiPhysics)

**是什么**:Vindictus 游戏用的 UE 插件 KawaiiPhysics 的算法。每条骨链每一步往「动画里的姿势」拉回一点(刚度),
速度按阻尼衰减;角色整体的移动、转动只传一部分(抵消整体移动 / 转动);离动画姿势最多偏「限角」度;骨头是带半径的球,
可以碰手臂 / 腿的胶囊;游戏里不加重力,形状一直保持动画姿势。插件按 60 Hz 逐帧算完,写成关键帧。
预设见附录 B.3;K1 是游戏身体蓝图的原值(刚度 0.05、阻尼 0.5、抵消 0.8、限角 10.8°、半径 5 cm)。

**插件里**:效果选择 → 某类 → 弹簧骨骼 → 预设,参数展开可改,点「模拟 / 烘焙」。

**手动**:MMD / PMXEditor 只有刚体,Blender 也没有自带的同类功能,所以**没有手动做法**。能手动的只有:
改参数重新烘;烘好的关键帧在曲线编辑器(Graph Editor)里手调;不想用插件就改用 MMD 刚体(第 2–4 节)。

## 7. 骨骼布料(Magica Cloth 2 风格)

**是什么**:照 ROE 游戏用的 Unity 插件 Magica Cloth 2 做的骨链模拟。每根骨尾是一个质点,往动画姿势的角度拉回(角度恢复),
离动画最多偏「角度限制」(从根到梢逐渐放宽),身体的移动只传一部分(惯性、限速),背后有「背挡」不让往身体里翻,
会碰腿和胯的胶囊、地面;每秒 90 步(30 fps × 子步数 3),写成关键帧。主要用来让裙子不穿腿。预设见附录 B.4。

**插件里**:效果选择 → 某类 → 骨骼布料。效果选择里的版本比独立插件多两项:**相邻链连接**(环形裙子的裙片不分开)、
**腿里的重叠也放过**。

**手动**:用你 Blender 里已经装好的独立插件「骨骼布料」(N 侧栏「骨骼布料」页签),参数同名同义:

1. 「找出骨链」,要模拟的组选「骨骼布料模拟」,不要动的选「跟随动画」或「MMD 物理」;
2. 「加腿和胯的碰撞体」(裙子要,头发不要);
3. 预设选「裙子 / 头发 / 游戏原值」,再照附录 B.4 改成想要的那一行(比如 ROE 戳的时候、飘一点);
4. 「模拟并烘焙」;「还原」回到烘焙前。

## 8. 跟随骨骼

**是什么**:不模拟。这一类骨上的刚体改成跟骨:动作里有这些骨的关键帧(游戏导出的动作)就照关键帧走,没有就跟着身体。

**手动**:PMXEditor 把这些刚体的物理演算改成 ボーン追従;Blender 在 MMD Rigid Body 里把 Rigid Type 改成「骨骼」,
然后 Clean → Build。

## 9. 全局设置(只影响 Blender 渲染)

### 9.1 物理步长

刚体每秒算几步。Blender 默认每帧 10 步(30 fps 下 300 Hz),关节「硬」;MMD 是 60 Hz,关节「软」。RGBA 这类靠关节「软」
才晃的结构,在 300 Hz 下整套锁死不动,要 60 Hz。插件选「自动」时,胸部用了 RGBA 就按 60 Hz 算,否则不动场景的设置。

**手动**:场景属性 → 刚体世界环境 → 每帧子步数:2 = 60 Hz,4 = 120 Hz,10 = 300 Hz(30 fps 时)。

### 9.2 MMD 同款

mmd_tools 直接 Build 出来的物理和 MMD 差很多,插件每次都做这几项:

1. 场景属性 → 重力 Z 填 **−7.84** m/s²(MMD 的 98 单位/秒² ÷ 12.5);
2. 每个关节:物理属性 → 刚体约束 → 弹性:弹簧类型选 **Blender2.7**;六个轴的阻尼都填 **0**(Blender 把这种弹簧的阻尼
   取反,0 才等于 MMD);角度三轴的硬度 = Spring(Angular) **÷ 156.25**(12.5²,旋转弹簧的量纲带长度的平方);
   线性三轴的硬度 = Spring(Linear),不变;
3. 和所有组都不碰的刚体(Collision Group Mask 16 个全亮):物理属性 → 刚体 → 碰撞 → 集合,每个只勾一个没人用的层
   (20、19……各占一个)。mmd_tools 只给开始时挨着的刚体加了不碰撞约束,不这样做,手臂甩过来照样会把胸顶开;
4. 帧率 30 fps。

mmd_tools 的 Build 会把第 2 项重设回去,所以要在 Build 之后做。

### 9.3 开头保持一帧

Blender 在模拟的**第二帧**才按各刚体当时的位置建关节。跟骨的刚体那时已经摆到第二帧的姿势,摆动刚体和关节还在第一帧,
这一帧的差就永久留在关节里(胸、头发、裙子整段偏一点);而且新开的 Blender 第一次模拟和播放过一遍以后,错位不一样,
结果也不一样(ROE + Tda 式:3.75° 对 2.81°)。插件把动作副本的第二帧改成和第一帧一样,原动作不动。

**手动**(在动作的副本上做):姿态模式全选骨 → 跳到第 1 帧 → 姿态 → 复制姿态 → 跳到第 2 帧 → 粘贴姿态 → 插入关键帧
(位置和旋转)。按 margin 导入的动作,只影响开头那 1 秒从静止到第一个姿势的过渡。

### 9.4 渲染前烘焙

播放时刚体是现算的,渲染前要烘成缓存:插件里点「烘焙刚体缓存(渲染前)」;手动是 场景属性 → 刚体世界环境 → 缓存 → 烘焙
(帧范围设成和场景一样)。

## 10. 按衣服推荐

**是什么**:胸部物理只带得动权重在胸骨上的顶点。衣服跟胸骨走得比底下的皮肤少,胸晃大了皮肤就从衣服里穿出来,
往前颠的套件(RGBA)最容易穿。插件比较每侧乳尖附近**最外面那层网格**和**皮肤**跟胸骨走多少:

| 最外层的胸骨权重 ÷ 皮肤的 | 种类 | MMD 刚体 | 弹簧骨骼 | 骨骼布料 |
|---|---|---|---|---|
| 最外层就是皮肤,或 ≥ 95 % | 裸着或贴身 | RGBA 式 | K1 | 不改 |
| 80–95 % | 衣服大致跟着 | Tda 式 | K1 | 不改 |
| < 80 % | 衣服只跟一部分 | C 方案(E) | 稳一点 | ROE 平时 |
| 乳尖前面挡着一层几乎不跟胸骨走的(不到皮肤的 20 %) | 挡着一层不跟胸的 | 紧实 | 稳一点 | ROE 平时 |
| 胸骨上没有网格 | 胸骨不带网格 | 不改 | 不改 | 不改 |

本机的例子:PCF_005 连衣裙 93 %(大致跟着,套 RGBA 渲出来皮肤顶出布面)、PCF_008 卫衣 79 %、PCF_009 西装 97–99 %、
PCF_067 钢甲胸骨上没有网格。

**手动**:选最外层的衣服网格 → 权重绘制模式 → 顶点组选胸骨那一组,在乳尖附近用「采样权重」(Blender 3.6 是 Ctrl + 右键)
读出权重;皮肤网格同一位置也读一个。两个相除,按上表选预设。

## 11. 胸部刚体调参(导出 PMX 给 MMD 用)

**是什么**:侧栏 MMD物理 → 胸部:读出模型的胸部刚体和关节,按 PMXEditor 的轴逐项改(左右联动、对称限位),套预设
(参考默认、柔软、Q弹、紧实、夸张、关闭物理,见附录 B.5),用测试动作预览,导出 PMX、存参数 JSON。

**手动**:在 PMXEditor 里照第 2 节改那几个数就是;或者在 mmd_tools 里改完,用 mmd_tools 的导出 PMX。

## 12. 新建胸部物理

**是什么**:模型没有胸部物理(甚至没有胸骨)时补上。插件按模型身高 H(PMX 单位,一般约 20)的比例做:

- 骨:每侧一根,挂在乳房区承重最多的上半身系骨下;骨头在乳尖正后方 0.058 H(约 1.16),骨尾就是乳尖。
- 权重:以乳尖为中心的高斯分布,范围 σ = 0.052 H(约 1.04),2.3σ 以外为 0;从胸部原有骨的权重里按比例分出来,
  每个顶点的总权重不变,中线附近不串到对侧。
- 刚体:球,半径 0.029 H(约 0.58),球心在骨头往骨尾 0.024 H 处;物理演算,碰撞组 16,谁都不碰。
- 关节:父骨链上第一个有刚体的骨的刚体 → 胸刚体,放在骨头上;父骨链上没有刚体就给父骨补一个跟骨的锚刚体。
- 建完套一个预设(默认 Q弹),之后随便调。
- 乳尖自动找;找偏了就在网格编辑模式选中乳尖附近的顶点,点「用选中顶点作乳尖」。

**手动 · PMXEditor**:照上面的比例加骨(左胸 / 右胸)、刷权重(乳尖一圈是 1,往外渐变到 0)、加球形刚体和关节,
手感参数用附录 B.5 的 Q弹。

## 13. 还原

**插件里**:效果选择 → 还原。刚体、关节、动作、重力、步长都回到第一次用之前,套件的刚体、加的碰撞体删掉。

**手动**:没有一键;开始前另存一份 .blend,或者重新导入 PMX 和 VMD。
